# FOCLYRA – AI-Powered Personalized Study Planner

## Problem Statement

Student enters subjects, exam dates and available study hours. The system generates a personalized study schedule.

## Proposed Solution

FOCLYRA is an AI-powered study planning platform that helps students organize subjects, priorities, exams, and available study time. It also provides AI assistance and tools to adapt study plans when situations change.

## Key Features

- Study Planner
- Smart Priority
- What-If Planning
- Focus Forecast
- Plan Rescue
- Plan Health
- Study Insights
- FOCLYRA AI
- Personalized Themes and Interface

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Groq API
- GitHub
- Render

## How It Works

1. Student enters subjects, exams, and available study hours.
2. FOCLYRA organizes the study requirements.
3. Important tasks are prioritized.
4. A personalized study plan is created.
5. Students can adapt the plan when situations change.
6. Study insights help students understand their planning.
7. FOCLYRA AI provides academic assistance.

## Target Users

College and university students who need help planning, prioritizing, and managing their study time.

## Expected Impact

- Makes study planning easier
- Helps students focus on important academic tasks
- Improves time management
- Helps students recover when plans change
- Provides AI-powered academic assistance
